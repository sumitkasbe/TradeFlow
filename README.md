# 🚀 TradeFlow

TradeFlow is a full-stack stock trading web application inspired by platforms like Zerodha. It provides authentication, holdings, positions, dashboard views, and a backend API connected with MongoDB.

## 🌐 Live Project

- **Live Frontend:** https://tradeflowfrontend.onrender.com/
- **Dashboard:** https://tradeflowdashboard.onrender.com/
- **Backend API:** https://tradeflowbackend.onrender.com/

## ✨ Features

- User Registration & Login
- Secure Authentication
- Stock Watchlist
- Holdings Management
- Positions Management
- Trading Dashboard
- MongoDB Database
- REST API
- React Dashboard
- Express.js Backend
- Responsive UI
